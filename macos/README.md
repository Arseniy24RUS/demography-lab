# Автономный запуск на Mac

Сначала распакуйте весь архив в постоянную папку. До занятия откройте `Prepare.command` и дождитесь завершения подготовки. Полный Mac-комплект уже содержит Node.js, приложение, оригиналы документов, статистику и зависимости; для его подготовки интернет не требуется. Исходная версия GitHub требует интернет на подготовительном этапе.

`Network.command` покажет локальные адреса и поможет открыть настройки общего доступа. Выберите заранее проверенную Wi-Fi сеть без изоляции клиентов. Самым воспроизводимым вариантом является отдельный роутер с DHCP без подключения WAN. Раздача Wi-Fi самим Mac зависит от доступных аппаратных интерфейсов; программа не меняет их автоматически.

`Start-Seminar.command` проверит комплект и запустит сервер без загрузок из интернета. `Stop-Seminar.command` сделает резервную копию и закроет базу. `Backup.command` создаёт дополнительную резервную копию.

Преподаватель и слушатели открывают одну ссылку и сначала вводят только email. Если профиль новый, следующим шагом указывают ФИО. Для роли преподавателя используйте `omnistat@yandex.ru`. ФИО, роль, «Изменить ФИО» и «Выйти» находятся в шапке приложения.

Данные по умолчанию сохраняются в `~/Library/Application Support/DemographyLab`, отдельно от программы. Подробная инструкция: `../docs/offline-macos.md`.

## Личные заметки и профиль в 0.8.2

После входа цитаты, авторские карточки и проверки сохраняются в базе Mac и доступны при повторном вводе того же email с другого устройства этой учебной сети. ФИО редактируется через шапку и сохраняется после перезапуска. Гостевые записи старых версий остаются в браузере; добавить их в профиль можно кнопкой «Добавить прежние заметки» в «Моя работа». Для скачивания дорожной карты используйте DOCX или PDF. Действия с JSON-архивами слушателям не нужны.
