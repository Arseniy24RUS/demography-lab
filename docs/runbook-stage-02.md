# Проведение совместной работы в версии 0.2

## Подготовка преподавателя

Запустите накопительный комплект локально и убедитесь, что открываются документы и карточки. Для работы группы разместите клиент и корпус по HTTPS, подключите Supabase по `supabase/README.md`, загрузите все редакции и проверьте настройку email-кода. Для локальной готовой сборки публичные настройки читаются из `public/workshop-config.json`; для статического хостинга файл должен лежать рядом с `index.html`.

Преподаватель подтверждает собственный email, указывает ФИО, получает назначение администратора и открывает «Занятия». Создавая занятие, задаёт название, уровень и регион. Уровень муниципалитета в этом выпуске обозначает контекст занятия; муниципальные командные дорожные карты относятся к этапу 5. Выбор региона не ограничивает исследование корпусом одного субъекта: сравнение других регионов остаётся доступным.

Откройте приглашение и покажите QR или код группе. Ссылка содержит только код входа. После сбора участников можно закрыть дальнейшее присоединение или заменить код, сохраняя уже принятых участников. Проверьте вход со второго устройства и открытие проектора до начала пары.

## Работа слушателя

Слушатель открывает «Занятия», вводит email, получает код и подтверждает его. После ФИО вводит код занятия либо использует ссылку с QR. ФИО подписывает учебные публикации; email не показывается другим участникам доски.

В разделе «Документы» слушатель выбирает программу, находит фрагмент, сопоставляет карточку и проверяет отдельные поля. Для публикации требуется хотя бы одна точная цитата из доступной на сервере редакции. «Отправить в занятие» открывает просмотр содержимого и поле комментария. «Опубликовать в занятии» передаёт карточку на сервер; подтверждение показывается после сохранения и проверки.

После публикации открывается общая доска. Слушатель может открыть исходный фрагмент, представить свою логику группе и изменить собственную карточку. Редактирование общей публикации не заменяет локальный черновик автоматически. Если две вкладки меняют одну карточку, второй редактор увидит конфликт и сможет сравнить версии; введённый текст сохраняется в форме.

## Режиссура обсуждения

| Этап | Действия преподавателя | Работа группы |
| --- | --- | --- |
| Чтение | Открыть приём работ и объяснить требования к основаниям | Найти фрагменты и подготовить публикации |
| Проверка | Переключить этап, выбрать карточку и открыть её на проекторе | Проверить механизм, получателей, суммы, условия и соответствие цитате |
| Обсуждение | Переключить этап и зафиксировать выбранный фокус | Обсудить переносимость меры, ограничения и требуемые изменения |
| Завершение | Закрыть занятие после итогового обсуждения | Сохранить локальные результаты в ZIP и при необходимости вернуться к чтению доски |

Публикация и авторская редактура доступны при `open` на этапах чтения и проверки. Этап обсуждения, пауза и закрытие прекращают отправку. Уже принятые участники продолжают чтение. Закрытие обратимо: преподаватель может возобновить сессию. При паузе новые слушатели могут присоединяться, если вход отдельно не закрыт.

Модерация преподавателя действует на всех этапах: неподходящую карточку можно убрать с общего показа, сохраняя её для автора и преподавателя, а затем восстановить. Автор может снять свою публикацию только во время открытой работы; восстановление выполняет преподаватель.

На проекторе показывается одна работа с её основанием. Соседние публикации не сдвигают выбранную карточку. Имена авторов скрыты по умолчанию и включаются явно. Для дискуссии используйте полноэкранный режим и переключение длинных цитат; свободный комментарий участника может содержать сведения, которые он сам вписал.

## Восстановление при затруднениях

| Ситуация | Действие |
| --- | --- |
| Занятия не подключены | Проверить `workshop-config.json` и перезапустить локальный сервер либо обновить файлы хостинга |
| Письмо содержит ссылку вместо кода | Проверить почтовые шаблоны, в которых должен использоваться `{{ .Token }}` |
| Нет кнопки создания занятия | Проверить назначение аккаунта в приватном реестре преподавателей |
| Код занятия не принят | Проверить актуальный код, открытое присоединение и отсутствие отзыва членства |
| Сервер не знает редакцию | Выполнить импорт корпуса; не заменять текст или идентификатор цитаты вручную |
| Связь временно отсутствует | Продолжить локальную работу; перед повторной отправкой проверить доску |
| Зафиксирован конфликт | Сравнить опубликованную версию с черновиком; не закрывать форму до решения |
| Проектор пуст после входа | Проверить преподавательскую роль, наличие видимых публикаций и сеть |
| Локальная тетрадь оказалась другой | Вернуться к прежнему адресу, порту и профилю браузера либо импортировать ZIP |

## Перед настоящим занятием

На выбранном размещении необходимо проверить доставку реального письма на собственный адрес преподавателя, вход второго участника, обмен с двух устройств, восстановление после обрыва связи, проектор и закрытие приёма. Подтверждение этой процедуры относится к конкретному проекту и его почтовой конфигурации. Результаты выполненных проверок кода перечислены в `docs/stage-02-acceptance.md`.
