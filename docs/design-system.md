# Дизайн первого модуля

Рабочее пространство наследует палитру family-support. Визуальный ориентир — созданный для первого модуля полноэкранный концепт: светлая библиотечная колонка, широкий читательский экран и инспектор документальных оснований. Оформление предназначено для содержательной работы с первоисточником.

| Элемент | Решение |
|---|---|
| Фон | Белый #ffffff; фон рабочей области #f6f8fb |
| Текст | #142238, вторичный #52647b |
| Основной цвет | #123c73; активный #2e6bc3 |
| Акцент | #d45249; только значимое состояние |
| Границы | #dce4ee |
| Типографика | Системный Inter/Segoe UI/Roboto/Arial; явные размеры контролов |
| Радиусы | 8–12 px для контролов и панелей |
| Графика | Векторные иконки Lucide; растровые макеты не являются интерфейсом |
| Desktop | Шапка, заголовок задачи, библиотека / документ / инспектор |
| Mobile | Тот же порядок задач, переключение Библиотека / Документ / Связь, полноразмерные поля |
| Motion | Короткие переходы состояний с поддержкой reduced-motion |

Навигация первого этапа содержит «Документы», «Практики», «Моя работа». Верхнее действие — «Сохранить архив». Сцена: «Документы и практики», пояснение «Найдите фрагмент и проверьте основание меры». Кнопки, необходимые для реальных сценариев и отсутствующие в статическом концепте, добавляются в пределах той же системы: выбор абзаца, поиск цитаты, переход к странице, проверка полей, создание карточки и импорт работы. Содержимое источников берётся из реальных файлов; демонстрационный текст растрового концепта не переносится в корпус.

Состояния связи: «Предложено», «Проверено по источнику», «Есть расхождения». Точность текстового якоря и содержательная проверка меры представлены отдельно. Сохранение называется локальным до подключения backend. Неподготовленный документ имеет явный статус и ссылку на доступный исходник.

Первичный функциональный маршрут проверки: выбор программы → поиск → выделение текста или выбор абзаца → сопоставление с практикой → проверка отдельных полей → сохранение → обратный переход к цитате → восстановление после перезагрузки → экспорт и импорт.
