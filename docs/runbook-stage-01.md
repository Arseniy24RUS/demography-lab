# Порядок эксплуатации модуля 0.1

Этот документ относится к реализованной работе с документами, цитатами и практиками. Он описывает локальный запуск готовой сборки и подготовку статического HTTPS-размещения. План последующих совместных модулей приведён отдельно в `architecture-stage-01.md`.

## Подготовка компьютера преподавателя

Проверьте, что установлен Node.js 22.12 или новее:

```bash
node --version
```

В распакованном комплекте должны находиться `scripts/serve.mjs`, `dist/index.html`, файлы `dist/assets`, `public/data/corpus/index.json`, подготовленные документы и каталог. Папка `node_modules` для готового комплекта не нужна. Отсутствие дублирующей папки `dist/data` допустимо: локальный сервер использует `public/data`.

Откройте терминал в корневом каталоге и выполните:

```bash
node scripts/serve.mjs
```

Сервер напечатает адрес `http://127.0.0.1:4173/`. Откройте его непосредственно в браузере. Не заменяйте `127.0.0.1` на `localhost` при продолжении уже начатой работы: для IndexedDB это другой origin. Завершение сервера через `Ctrl+C` не удаляет сохранённую браузером тетрадь.

Вся работа с включёнными текстами выполняется из локального комплекта. Для кнопок открытия PDF-оригинала и исходной интернет-карточки потребуется внешний интернет. PDF не включены в архив сборки.

## Проверка перед демонстрацией

| Проверка | Наблюдаемый результат |
| --- | --- |
| Открытие приложения | Появляются библиотека, документ и панель сопоставления; отсутствует сообщение об ошибке загрузки |
| Выбор программы | Открывается выбранный регион, его паспорт и файловые страницы |
| Поиск | Ввод фразы даёт найденные фрагменты; переход открывает соответствующую страницу |
| Сохранение цитаты | Выделенный текст появляется в «Моя работа»; после перезагрузки остаётся тем же фрагментом той же редакции |
| Проверка поля | Сохранено отношение цитаты к выбранному полю и его значению; другие поля не получают подтверждение автоматически |
| Полный каталог | Кнопка загрузки подключает исходные карточки, включая федеральные; неподготовленные основания видны как непроверенные |
| Экспорт | Браузер сохраняет ZIP с `workspace.json`; в профиле экспортированного JSON значение `null` |
| Импорт | До добавления показана информация о файле; отметки импортированной проверки требуют подтверждения |

Для содержательной демонстрации удобно сопоставить предложение Мордовии о выплате 150 тыс. руб. на странице 64 программы и исходную карточку `sovetmam:mord-001` с суммой 100 тыс. руб. У них различаются статус утверждения, условия и момент источника. Обсудите, что именно подтверждает каждый текст. Расхождение двух снимков само по себе не доказывает ошибку одного из источников и не устанавливает действующую норму.

Необязательный профиль заполняется в «Моя работа». На общем компьютере один профиль браузера и один origin открывают одну тетрадь. Смена введённого ФИО не переключает независимые пользовательские аккаунты.

## Работа слушателя

Начните с выбора программы и просмотра её паспорта. Сохраните точный фрагмент с кратким пояснением, затем выберите карточку для сопоставления. При проверке отдельно рассматриваются механизм, получатели, размер и условия. Название задаётся в карточке. Укажите подтверждение, частичное подтверждение или противоречие только для тех полей, к которым относится фрагмент.

Авторская карточка создаётся для выбранного региона. Если подходящего описания нет, оставьте неизвестные сведения незаполненными и сформулируйте проверяемое предложение. Федеральная карточка сохраняет федеральную область действия; для документирования её региональной реализации создаётся отдельный региональный вариант.

На сенсорном экране доступны мобильные панели и выбор целых блоков. Точный диапазон можно выделить средствами браузера. Перед сохранением сверьте цитату в панели действия. Разрывы слов и сложные таблицы сверяйте с PDF: извлечённый текст не восстанавливает семантику табличных ячеек автоматически.

К окончанию работы сохраните ZIP-архив. Экспорт исключает локальное имя и email, но сохраняет содержимое цитат и заметок. Внесённый пользователем произвольный текст не анонимизируется автоматически. Сервер не собирает архивы; передачу файлов организует преподаватель выбранным способом вне этой версии приложения.

## Телефоны и общий адрес занятия

Локальный сервер привязан к `127.0.0.1`; IP-адрес компьютера в локальной сети не является адресом этого сервера для телефона. Для участников, работающих со смартфонов, подготовьте статическое HTTPS-размещение.

В корне сайта размещаются содержимое `dist`, включая `assets` и значки, и каталог `data`. После обычной сборки `npm run build` данные уже находятся в `dist/data`. Для сокращённого релизного архива скопируйте `public/data` в `data` опубликованной сборки. Исходные каталоги `apps`, `packages`, `tests` и npm-зависимости размещать как доступные файлы сайта не требуется.

Хостинг должен отдавать JSON как `application/json`, GeoJSON как `application/geo+json`, JavaScript и CSS с соответствующими MIME-типами. Отсутствующий файл данных должен отвечать 404. Перенаправление неизвестных `.json` на `index.html` приведёт к явной ошибке загрузки. Для объёмных текстов желательно включить gzip или Brotli на хостинге.

Если хостинг устанавливает CSP, разрешите скрипты, worker и соединения с тем же origin. Для используемых React inline styles требуется `style-src 'self' 'unsafe-inline'`; разрешать inline scripts не нужно. Политика локального сервера приведена в `scripts/serve.mjs`. Внешние PDF открываются ссылками, а не подключаются как скрипты или встраиваемые объекты.

Проверьте опубликованный адрес на компьютере и на телефоне до занятия. Доступ к одному сайту обеспечивает одинаковые источники, но версия 0.1 сохраняет результаты на каждом устройстве отдельно.

## Перенос и восстановление

| Ситуация | Действие |
| --- | --- |
| Смена браузера или компьютера | На исходном устройстве сохраните архив; на новом откройте «Моя работа → Импортировать работу» |
| Смена порта, домена или HTTP/HTTPS | Сначала экспортируйте тетрадь с прежнего адреса; затем импортируйте по новому адресу |
| Удаление данных сайта | Восстановите работу из ранее сохранённого ZIP/JSON; текущая версия не имеет серверной резервной копии |
| Конфликт двух вкладок | Сохраните введённый текст вне формы, если он ещё не записан; перечитайте актуальное состояние и повторите осмысленное изменение |
| Ошибка квоты или запрет IndexedDB | Экспортируйте доступную сохранённую работу, если интерфейс позволяет; откройте обычный профиль поддерживаемого браузера и импортируйте архив |
| Импорт сообщает о другой цитате или редакции под тем же ID | Сохраните оба файла; не подменяйте идентификаторы вручную. Установите происхождение расхождения и повторите импорт корректной версии |
| Сохранённая цитата не совпадает с текущим корпусом | Откройте исходную редакцию по сохранённому происхождению; текущие позиции не следует автоматически переносить в изменённый текст |

Тетрадь внутри архива ограничена 5 МиБ, входной файл — 8 МиБ. Архив не удостоверяет автора. При повторном импорте существующие объекты сохраняются, новые добавляются; положительные отметки чужой проверки становятся кандидатами для локального подтверждения.

## Типовые проблемы запуска

| Сообщение или наблюдение | Причина и способ проверки |
| --- | --- |
| Команда `node` не найдена | Node.js не установлен либо терминал не видит его в PATH; установите поддерживаемую версию и откройте терминал заново |
| Требуется Node.js 22.12+ | Текущая версия ниже минимальной; проверьте `node --version` |
| Готовая сборка не найдена | Комплект распакован не полностью или содержит только исходники; восстановите `dist` из релиза либо выполните `npm ci` и `npm run build` |
| Порт занят | Остановите прежний процесс либо задайте другой `PORT`; прежняя тетрадь останется связана со старым origin |
| Сервер вернул страницу вместо данных | Проверяйте фактический путь `data/corpus/index.json` и правила HTML-fallback на хостинге |
| Документ не имеет подготовленного текста | Смотрите паспорт: для девяти записей исходный файл отсутствует или недоступен; это не ошибка сервера |
| В документе есть пустая страница | У Московской области две страницы не дали текстового слоя; используйте оригинал PDF |
| PDF не открывается | Нужен интернет и доступ к внешнему источнику; полный PDF не является частью локального комплекта |
| На телефоне не открывается `127.0.0.1` | Это адрес самого телефона; используйте подготовленный HTTPS-адрес приложения |

## Проверки после изменения кода или выпуска

Для разработчика предусмотрены следующие команды:

```bash
npm ci
npm run build
npm test
node --test tests/server.test.mjs
```

Браузерные сценарии выполняются отдельно через Playwright после установки соответствующего браузера. Тест сервера не требует npm-зависимостей: он создаёт временный комплект, запускает дочерний Node-процесс и проверяет его HTTP-ответы из того же процесса тестирования. Это также позволяет проводить проверку в среде, где разные внешние команды получают разные сетевые пространства.

В выполненном прогоне серверного теста подтверждены доставка сборки, fallback данных, MIME/CSP, запрет доступа к исходникам и симлинкам за границами дерева, gzip/HEAD/304, обновление кеша и запрет методов записи. Получено 7 pass: шесть сценариев и общий тест. Полный фактический протокол проверки выпуска находится в `release-qa.md`; сценарии приёмки и ограничения локального хранения — в `stage-01-acceptance.md`.

После переимпорта корпуса выполняйте оба скрипта подготовки: сначала импорт канонических версий, затем пересоздание карточек и точных якорей. Порядок и исходный коммит указаны в `scripts/ingest/README.md`. Обновление программы без пересоздания связанных версий и якорей не является корректным обновлением корпуса.
