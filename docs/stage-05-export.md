# Экспорт дорожной карты

В разделе «Проверка и экспорт» команда выбирает до десяти разделов документа и скачивает Word или PDF. По умолчанию выбраны все разделы. В отчёт входят заполненные выбранные разделы; для текущей карты используются сохранённые командой данные, включая только что автоматически сохранённый паспорт. Скачивание читает согласованный снимок и не расходует лимит сохранённых версий. Кнопки рядом с явно зафиксированной версией выгружают именно её содержание.

Оформление использует параметры [ГОСТ Р 7.0.97–2025](https://protect.gost.ru/gost/details/360994e3-9a70-47b9-ab3a-cf21809e26ed): лист A4, поля 20 мм сверху, снизу и слева, 10 мм справа, основной текст Times New Roman 14 пт, выравнивание по ширине, абзацный отступ 1,25 см, межстрочный интервал 1,5. Номер страницы располагается по центру сверху со второй страницы. Таблицы компактнее основного текста; рисунки и таблицы имеют последовательную нумерацию.

Word использует шрифт, установленный на устройстве, и сохраняет редактируемые абзацы и таблицы. PDF встраивает обычное и полужирное начертания Times New Roman с устройства, если браузер выдаёт к ним доступ. При необходимости можно выбрать два локальных файла шрифта: они не передаются на сервер. На устройствах без этих файлов доступен явно выбираемый Liberation Serif, который поставляется на условиях SIL Open Font License. PDF сохраняет кириллицу как текст и рисует графики векторами.

В текущую версию можно включить графики годовых наблюдений для выбранной территории из проверенного набора платформы. Уже закреплённые наблюдения не подменяются новым рядом. При выгрузке предыдущей версии остаются её закреплённые данные. Пропуски остаются разрывами, ноль остаётся числом. Прогнозы по отдельным показателям используют сохранённые сценарии; график передвижки возрастов использует общие параметры проекта из экспортируемой версии. При отсутствии заданного варианта текущая карта показывает базовый расчёт, если для территории опубликованы исходные данные модели. История, база и вариант команды визуально различаются.

Публичный документ включает названия источников и содержательные ограничения, когда они нужны для чтения данных. Ссылки на файлы данных, номера редакций статистических рядов, хеши и служебные сведения не выводятся в Word и PDF. PDF не содержит скрытого JSON, вложений или технического снимка.

## Проверка и технические форматы

`prepareRoadmapExport` проверяет соответствие канонического снимка версии контрольной сумме, статистические ряды, перенесённые основания и финансовый итог. Некорректные данные не подменяются приближением. JSON и ZIP предназначены для технических проверок. Точные байты снимка доступны в отдельном `canonical.json` внутри ZIP. Прежние снимки без поля параметров передвижки возрастов поддерживаются.

Для быстрой регрессии: `npx vitest run tests/unit/roadmap-export.test.ts tests/unit/roadmap-export-browser.test.ts tests/unit/roadmap-export-figures.test.ts tests/unit/statistics-export.test.ts`. `tests/offline/shared-workspace.e2e.mjs` проходит через интерфейс участника, проверяет автоматическое сохранение, общий прогноз и выгрузку текущих и сохранённых документов. Путь к установленным TTF для проверки PDF с Times New Roman можно передать через `PLAYWRIGHT_TIMES_FONT_DIR`.
