# Объективные факторы рождаемости

Участники выбирают субъект РФ, муниципальное образование или входящее в него городское или сельское поселение. Карточки упорядочены по убыванию модуля корреляции. Выбранные связи появляются на общем флипчарте занятия. У карточки видны число территорий и голоса участников. Рейтинг определяется числом лайков. Доску можно открыть на проекторе.

## Муниципальные карточки

Результирующий показатель — опубликованный общий коэффициент рождаемости за год, в промилле. Для каждого показателя берутся все общие годы с числовыми значениями. Единица измерения, период, разрез показателя и территория должны совпадать внутри ряда. Месячный или квартальный ряд за один и тот же период сопоставляется с годовой рождаемостью в соответствующих годах. Оценка доступна при четырёх и более совместных годах и ненулевой дисперсии обоих рядов.

Байесовская оценка использует преобразование Фишера `z = arctanh(r)` для выборочной корреляции Пирсона. При наблюдении `z` с дисперсией `1/(n−3)` и априорной нормальной моделью `N(0, 1)` вычисляются медиана и центральный 95% интервал апостериорного распределения. Их границы переводятся обратно на шкалу корреляции через `tanh`. Карточка показывает медиану, интервал и число общих лет.

Источник — Росстат, обработка «Если быть точным», версия 112 от 28.09.2026, CC BY 4.0. [БДМО](https://doi.org/10.48612/tochno/bdmo)

Для выбора поселений сопоставлены первые пять цифр ОКТМО и наименование района в БДМО. Карточки доступны для 15 562 отдельных городских и сельских поселений. Семь поселений входят в исторический Тигильский муниципальный район, который присутствует в БДМО нижнего уровня. Названия и годы соответствуют исходным записям.

## Региональные карточки

Результирующий показатель — суммарный коэффициент рождаемости, детей на одну женщину. Значения взяты из опубликованных матриц А. М. Ситковского «Bayesian Correlations of Russian Regions». Формула источника корректирует выборочную корреляцию Пирсона по числу общих лет `r × (1 − (1 − r²)/(n − 2))`. Общие годы восстановлены по аналитической таблице и проверены воспроизведением опубликованных коэффициентов с точностью до округления. Для связи с плотностью населения в Ставропольском крае сохранён опубликованный коэффициент −0,61 с отметкой об отсутствии сведений о годах. В источнике доступны 4 809 связей для 85 субъектов. Для Архангельской и Тюменской областей использованы опубликованные ряды без входящих в них автономных округов. [Исходный проект](https://github.com/Arseniy24RUS/Bayes-correlations-of-Russia/tree/5dcd222bc5f41a8b310cb4769df424d998c91b1a) [Условия использования исходных данных](https://github.com/Arseniy24RUS/Bayes-correlations-of-Russia/blob/5dcd222bc5f41a8b310cb4769df424d998c91b1a/THIRD_PARTY_NOTICES.md)

При добавлении на флипчарт связь учитывается для каждого отдельного знака. Региональные и муниципальные карточки объединяются по пяти согласованным показателям. Это число прибывших, число выбывших, миграционное сальдо, численность населения на 1 января и площадь жилых помещений на жителя. Региональная и муниципальная карточки сохраняют название своего показателя рождаемости.

## Обновление

Скрипт `scripts/prepare-municipal-correlations.py` проверяет контрольные суммы всех 33 разделов локального пакета OmniStat. Для запуска нужны Python 3.11+ и DuckDB. Параметр `--crosswalk` принимает таблицу соответствий муниципалитетов текущей «Диагностики». Запуск с `--level upper` готовит каталог округов и районов для `public/data/factors`, запуск с `--level lower` готовит каталог поселений и других территорий для `public/data/factors/lower`. Каждый запуск принимает путь к исходному пакету `--package`, новый путь для каталога `--out` и путь к отчёту `--qa`. Клиент загружает каталог выбранного уровня и один файл на муниципалитет.

Команда `python scripts/prepare-objective-geography.py --upstream <каталог исходного проекта>` требует openpyxl и проверяет контрольные суммы двух книг исходного проекта. Она собирает региональные карточки и иерархию поселений по готовым каталогам БДМО.
