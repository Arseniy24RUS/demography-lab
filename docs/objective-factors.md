# Объективные факторы рождаемости

Сразу после первого флипчарта участники выбирают муниципалитет и просматривают карточки показателей в порядке убывания модуля корреляции. Выбранные карточки появляются на общей доске занятия. Участники голосуют за или против каждой карточки, меняют или снимают свой голос. Рейтинг считается по разности голосов за и против. Доску можно открыть на проекторе.

## Расчёт

Результирующий показатель — опубликованный общий коэффициент рождаемости за год, в промилле. Для каждого показателя берутся все общие годы с числовыми значениями. Единица измерения, период, разрез показателя и территория должны совпадать внутри ряда. Месячный или квартальный ряд за один и тот же период сопоставляется с годовой рождаемостью в соответствующих годах. Оценка доступна при четырёх и более совместных годах и ненулевой дисперсии обоих рядов.

Байесовская оценка использует преобразование Фишера `z = arctanh(r)` для выборочной корреляции Пирсона. При наблюдении `z` с дисперсией `1/(n−3)` и априорной нормальной моделью `N(0, 1)` вычисляются медиана и центральный 95% интервал апостериорного распределения. Их границы переводятся обратно на шкалу корреляции через `tanh`. Карточка показывает медиану, интервал и число общих лет.

Источник — Росстат, обработка «Если быть точным», версия 112 от 28.09.2026, CC BY 4.0. [БДМО](https://doi.org/10.48612/tochno/bdmo)

## Обновление

Скрипт `scripts/prepare-municipal-correlations.py` проверяет контрольные суммы всех 33 разделов локального пакета OmniStat. Для запуска нужны Python 3.11+ и DuckDB. Параметр `--crosswalk` принимает таблицу соответствий муниципалитетов текущей «Диагностики». Запуск с `--level upper` готовит каталог округов и районов для `public/data/factors`, запуск с `--level lower` готовит каталог поселений и других территорий для `public/data/factors/lower`. Каждый запуск принимает путь к исходному пакету `--package`, новый путь для каталога `--out` и путь к отчёту `--qa`. Клиент загружает каталог выбранного уровня и один файл на муниципалитет.
